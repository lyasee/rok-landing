1. 적용 범위와 운영자

이 문서는 알오케이지지(ROKGG)가 제공하는 메코디 2.0 앱과 메코디 소개 페이지의 개인정보 처리 방식을 설명하는 문서입니다. 2026년 9월 8일부터 적용하며, 현재 공개된 구버전의 방침을 소급하여 대체하지 않습니다.

메코디는 코디를 미리 조합하고 저장하는 서비스입니다. 앱 자체의 회원가입을 요구하지 않으며, 게임 계정의 아이디·비밀번호, 주민등록번호, 연락처 목록을 입력받는 기능을 제공하지 않습니다.

운영자 및 개인정보 문의: 알오케이지지 메코디 운영 담당 · notice.rokgg@gmail.com

2. 기기에 보관하는 정보

코디 슬롯, 선택한 아이템·색상·피부·표정·자세, 대표 코디 설정, 광고 보상으로 확보한 슬롯 한도, 구매 혜택 확인 결과는 앱의 기기 내 저장소에 보관됩니다. 코디 보관함 전체를 운영자의 별도 서버로 자동 업로드하거나 계정 간 동기화하지 않습니다.

PNG 저장을 선택하면 완성 이미지가 이용자의 사진첩에 저장됩니다. 사진첩의 다른 사진을 읽어 운영자에게 전송하는 기능은 없습니다. 기기 운영체제의 백업 설정에 따라 앱 데이터나 사진이 Apple·Google 등의 백업 서비스에 별도로 보관될 수 있습니다.

3. 기능 이용 시 외부로 전달되는 정보

기기에 코디를 저장한다는 사실이 모든 데이터가 기기 밖으로 나가지 않는다는 뜻은 아닙니다. 다음 기능에는 외부 통신이 필요합니다.

앱 오류 보고현재 배포 빌드에서는 자동 수집하지 않음Firebase Crashlytics 패키지는 포함되어 있으나 Android·iOS 자동 수집을 비활성화했습니다. 향후 활성화 시 별도 고지와 설정 갱신이 필요합니다.
기존 구매 복원상품 식별자, 스토어 구매 상태, 가능한 경우 구독 유효기간·취소 정보, 거래 확인 정보Apple App Store 또는 Google Play에서 과거 유효 PRO 권리를 확인합니다. 앱은 새 결제를 받지 않습니다.
이메일 문의이메일 주소, 문의 내용, 이용자가 직접 보낸 첨부파일문의를 접수하고 답변하기 위해 운영자에게 전달됩니다. 게임 비밀번호나 불필요한 민감정보를 보내지 마세요.

광고 SDK의 IP 주소 처리로 국가·지역 수준의 대략적인 위치가 추정될 수 있습니다. 이는 메코디가 GPS 정밀 위치 권한을 요청한다는 뜻이 아닙니다. 광고 식별자 처리는 운영체제 권한, 동의 상태, SDK 설정에 따라 달라집니다.

Google이 안내하는 항목은 Android 광고 SDK 데이터 공개 문서와 iOS 광고 SDK 데이터 공개 문서에서 확인할 수 있습니다.

4. 광고·분석 설정과 이용자의 선택

메코디 2.0의 현재 구현은 비개인화 광고를 요청하도록 설정되어 있습니다. 비개인화 광고도 광고 전달, 보안, 빈도 제한 등을 위한 일부 데이터 처리가 있을 수 있습니다. 추적 허용이나 광고 클릭을 슬롯 보상의 조건으로 삼지 않습니다.

지역에 따라 필요한 동의 절차는 UMP에서 안내합니다. 앱의 설정에서 제공되는 광고 개인정보 선택과 기기 설정의 광고·추적 제어를 이용할 수 있습니다. 광고 요청이 제한되거나 광고가 준비되지 않아도 기본 코디 편집, 확보한 슬롯 이용, 기본 PNG 저장을 막지 않습니다. 추가 슬롯 보상은 광고 제공이 가능한 경우에 이용할 수 있습니다.

Firebase Analytics는 최초 실행 시 기본적으로 수집을 시작하지 않으며, 이용자가 “이용 통계 수집 허용”을 선택한 뒤에만 수집을 활성화합니다. 허용하면 Google이 앱 설치를 구분하기 위한 의사식별자와 앱·운영체제·기기 정보를 처리할 수 있고, 화면 조회, 아이템 ID·종류 선택, 표정·자세 선택, 헤어·렌즈 혼합 색상과 비율, 슬롯 저장·삭제·덮어쓰기·대표 지정, 이미지 저장 완료와 같은 이벤트가 포함될 수 있습니다. Analytics 설정에서는 Android 광고 ID·SSAID와 iOS IDFV 수집을 끄고, 광고 저장·광고 사용자 데이터·광고 개인화 신호의 기본 허용도 끕니다. 이벤트에는 코디 슬롯 이름, 이메일 주소, 연락처, 사진첩 파일, 원본 이미지 파일을 넣지 않습니다. 이용자는 설정의 “이용 통계 설정”에서 거부하거나 철회할 수 있으며, 철회 이후 새 이벤트 전송을 중단합니다. 이미 전송된 데이터의 삭제·보유는 Google Analytics 정책과 설정을 따릅니다.

이 설정과 Firebase Crashlytics의 오류 보고, AdMob의 광고 측정은 서로 다른 기능입니다. 현재 Crashlytics 자동 수집은 비활성화되어 있습니다. Analytics 수집 동의를 거부했다고 해서 광고 SDK의 처리가 자동으로 중단되는 것은 아니며, 각 기능의 선택 방법은 이 문서의 해당 항목과 앱 설정에 따릅니다.

5. 보유기간과 삭제

기기에 저장된 코디는 앱의 슬롯 삭제 기능으로 삭제할 수 있습니다. 사진첩에 저장한 PNG는 기기의 사진 관리 기능에서 별도로 삭제해야 합니다. 앱 데이터 삭제·앱 제거와 사진첩 파일 삭제는 서로 다를 수 있습니다. 운영체제 백업에 들어간 사본은 해당 백업 서비스에서 관리해야 합니다.

광고 보상 및 기존 구매 권한의 기기 내 기록은 앱 데이터와 함께 보관됩니다. 삭제하면 기기 내 기록은 없어질 수 있고, 실제 구매 권리는 같은 스토어 계정의 유효 거래 조회를 통해 다시 확인합니다. 운영자는 카드번호나 스토어 비밀번호를 수집하지 않습니다.

현재 배포 빌드에서는 Crashlytics 자동 수집을 하지 않습니다. 향후 오류 보고를 활성화하는 경우 Firebase는 Crashlytics의 충돌 기록과 관련 식별자를 90일 보관한 뒤 삭제 절차를 시작한다고 안내하며, 그 시점에 수집 범위·보유기간·동의 및 스토어 신고 내용을 함께 갱신합니다. 외부 제공자의 실제 처리 범위와 보유기간은 Firebase 개인정보 안내 등 해당 서비스 문서를 따르며, 모든 외부 서비스에 같은 기간이 적용되는 것은 아닙니다.

문의 이메일과 첨부자료는 문의 접수와 답변을 위해 보관하며, 별도 보존기간을 두지 않고 이용자가 삭제를 요청하면 지체 없이 삭제합니다. 법령상 보존이 필요한 경우에는 해당 기간 동안 보관한 뒤 삭제합니다. 운영자는 문의 처리 목적을 벗어난 이메일 활용을 하지 않습니다.

6. 외부 서비스와 국외 처리

Analytics와 광고에는 Google의 서비스가, 과거 구매 복원에는 Apple·Google 스토어가 관여합니다. 현재 Crashlytics 오류 보고 자동 수집은 비활성화되어 있습니다. 요청 시 외형 이미지는 넥슨 서버에서 전달됩니다. 외부 서비스는 각각의 개인정보 처리방침, 계약, 운영체제 권한에 따라 정보를 처리하며, 서비스별로 운영자의 위탁 처리인지 별도 개인정보처리자의 처리인지 구분해야 합니다.

Google 등 해외 사업자의 서비스를 통해 정보가 국외에서 처리될 수 있습니다. 다음은 현재 앱과 웹사이트에서 확인되는 국외 처리 내역입니다. Google·Apple·GitHub의 계정, 계약, 지역 설정에 따라 실제 처리 법인이나 처리 국가가 변경될 수 있으며, 변경 시 이 문서와 앱의 안내를 갱신합니다.

7. 소개 웹페이지의 처리

메코디 소개·약관 페이지에는 별도의 방문자 분석 스크립트나 광고 SDK, 회원가입 폼을 추가하지 않았습니다. 스토어 버튼을 누르면 해당 스토어로 이동하며 그 이후에는 각 서비스의 처리방침이 적용됩니다. 문의 링크는 이용자의 이메일 앱을 실행합니다.

사이트를 제공하는 GitHub Pages는 보안을 위해 방문자의 IP 주소를 기록한다고 안내합니다. 이는 운영자가 별도 분석 스크립트를 설치하는 것과 구분됩니다. GitHub Pages 데이터 수집 안내와 GitHub 개인정보처리방침을 참고하세요.

8. 권리 행사와 문의
