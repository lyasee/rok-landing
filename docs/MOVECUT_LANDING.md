# 무브컷 랜딩 페이지

작업일: 2026-09-09. 기존 rok-landing의 Astro 정적 페이지 및 앱 레지스트리에 연결했습니다. 운영 사이트 배포나 Git push는 수행하지 않았습니다.

## 주소와 구조

- `/movecut/`: 무브컷 소개 페이지.
- `/movecut/privacy/`, `/movecut/terms/`: 기존 공개 법률 문서 유지.
- `/`: 앱 레지스트리의 visible 설정에 따라 무브컷 소개 카드 자동 노출.
- `/sitemap.xml`: 무브컷 랜딩과 기존 공개 문서 자동 포함.

`src/pages/[app]/index.astro`에서 무브컷만 `src/components/landing/MoveCutLanding.astro`를 사용합니다. 다른 앱은 기존 공통 템플릿을 유지합니다. 스타일은 `src/styles/movecut.css`에 분리했습니다. 새 정적 라우트 파일을 중복 생성하지 않았습니다.

## 디자인과 에셋

아이보리·코랄 색상과 러닝 사진, 종이 카드가 겹치는 구성을 사용합니다. 대표 3종 소개, 제공된 홍보 이미지, 3단계 사용 방법, 라이트·다크 앱 화면 전환, FAQ, 스토어 안내, 기존 법률 문서 링크가 있습니다. 카드 및 홍보 이미지 확대는 dialog를 사용하며 Esc 닫기와 원래 버튼으로의 포커스 복귀를 지원합니다.

제공된 홍보 이미지 중 `무브컷_달린_오늘을_기록하다.png`를 WebP로 변환해 사용했습니다. 홍보 이미지는 실제 캡처라고 표기하지 않습니다. 대표 카드 3종과 라이트·다크 화면은 기존 movecut 프로젝트의 실제 내보내기·검증 결과물을 사용했습니다. 출처·크기·파일 용량은 `docs/movecut-assets.json`에서 확인합니다. 모든 이미지는 이 프로젝트의 public 폴더에 포함되어 외부 이미지 서버에 의존하지 않습니다.

## 스토어 공개 시 변경

`src/content/apps/movecut.json`의 `stores.googlePlay` 또는 `stores.appStore`에 확인된 직접 스토어 주소를 넣고, 해당 `storeStatus`를 `available`로 변경합니다. 현재는 주소가 없어 양쪽 모두 `pending`이며 클릭되지 않는 공개 준비 중 안내를 표시합니다. `launchStatus`, `releaseLabel`, `releaseNote`, 마지막 FAQ의 출시·가격 답변도 실제 공개 정보에 맞게 함께 갱신하세요. 공통 StoreLinks 컴포넌트는 상태에 따라 링크를 생성합니다.

가격과 무료·유료 제공 범위는 확정하지 않았습니다. 임의의 스토어 주소, 할인 가격, 구매율, 순위 또는 리뷰를 넣지 않았습니다. 구조화 데이터도 가격·평점·리뷰를 포함하지 않습니다.
