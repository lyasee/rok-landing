## 공개 상태

메코디 개인정보처리방침과 이용약관은 운영자 확인 기준으로 2026-09-08부터 시행하는 공개본으로 전환했습니다. 문의 이메일은 별도 보존기간 없이 요청 시 삭제하며, 국외 처리 내역은 각 문서의 표에 기재했습니다.

`release:check`, 단위 테스트 19개, 브라우저 E2E 23개, Astro 검사, 정적 빌드, 포맷 검사를 통과한 뒤 `npm run deploy`로 GitHub Pages에 배포했습니다. 공개 URL에서 HTTPS·200 응답·본문·사이트맵 노출을 확인했습니다.

Google Play 링크는 기존 공개 버전으로 연결됩니다. 현재 앱 코드에 있던 한국 App Store 주소의 공개 페이지를 확인하지 못해 iOS 버튼은 공개 준비 중으로 표시하고 주소는 설정에 보존했습니다. 공개 여부가 확인되면 `storeStatus.appStore`를 변경하면 됩니다.

## 보존한 것

위고 소개·개인정보처리방침 원문, 기존 공통 스타일, CNAME, app-ads.txt는 HEAD와 바이트 비교에서 동일했습니다. 기존 위고의 `/wego`, `/wego/privacy` 주소와 슬래시 포함 주소를 모두 검사했습니다. 다른 앱의 다운로드 주소와 메코디 모바일 앱 소스는 변경하지 않았습니다.

메코디 화면 이미지에는 실제 실행 캡처만 사용했습니다. 알림·시스템 영역을 제외하거나 기능 영역을 잘라 WebP로 압축했고, 내부 UI·도트 캐릭터를 새로 그리지 않았습니다. 원본·변환 해시와 자른 범위는 `docs/mecodi-assets.json`에 기록했습니다.
