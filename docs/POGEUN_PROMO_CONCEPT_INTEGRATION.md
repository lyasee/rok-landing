# 포근일기 홍보 시안 연결 작업 · 2026-09-10

## 완료한 코드

`PogeunConceptGallery.astro`를 추가하고 기존 포근일기 소개 페이지에 연결했습니다.
5개 홍보 시안은 실제 캡처와 별도 영역이며, AI 생성 이미지와 현재 UI의 차이를 명시합니다.
전체 비율을 유지하는 이미지, 모바일 가로 스크롤, 큰 이미지 새 탭 열기, 대체 텍스트와 지연 로딩을 적용했습니다.
검증된 이미지 10개와 manifest가 없으면 갤러리를 렌더링하지 않습니다. 누락된 파일에 대한 깨진 링크를 표시하지 않습니다.

## 이미지 반입 상태

이 문서 작성 시 원본 ZIP이 Mac 다운로드 폴더에 없어 이미지 복사는 아직 완료되지 않았습니다.
대화에 제공된 `pogeun-promo-concepts-20260910.zip`을 다운로드한 다음 앱 프로젝트의 `import-promo-images.command`를 실행하세요.
스크립트가 ZIP·manifest·각 이미지의 SHA-256을 검증한 뒤 앱의 원본 5장과 웹용 10장을 복사하고 홈페이지를 빌드합니다.
다른 내용의 기존 파일은 덮어쓰지 않습니다. 실제 스크린샷·스토어용 이미지·문서 승인 상태는 바꾸지 않습니다.

## 검증 범위

홈페이지 콘텐츠 검사·Astro 검사·빌드와 단위 테스트는 통과했습니다.
포근일기 브라우저 검사 17개 중 15개 통과. 나머지 2개는 현재 published인 법적 문서를 draft로 가정한 기존 검사와 불일치했습니다.
법적 문서를 되돌리거나 테스트 기대값을 임의로 수정하지 않았습니다.
이미지 가져오기 전이므로 새 홍보 이미지 갤러리의 실제 이미지 로딩 검수는 아직 완료하지 않았습니다.
기존 실제 캡처 6개와 앱 소개 JSON의 해시가 작업 전과 동일한지 확인했습니다.
로그: `artifacts/pogeun-promo-integration/`.
